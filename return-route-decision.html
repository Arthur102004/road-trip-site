Return Route
Decision

The group wants to drop the Kansas return leg and instead loop back through New Mexico for a second UWC-USA Montezuma visit — but the new route needs one more driving day than the current plan, and the current schedule ends right on Arthur's booked return flight (Mon Aug 10). This page lays out the four ways to handle that, side by side, so we can pick together. The live itinerary is unchanged until we decide.

At a Glance

"Extra hotel night" = the new route needs overnight stops in Denver-area and/or Las Vegas NM that the old Kansas route never had. "Hotel-neutral" options swap one city's overnight for another's rather than adding a new one.

Shared charging notes

apply to all 4 options

The underlying Superchargers and mileages are identical no matter which option we pick — only which nights count as "overnight" changes. Two spots need extra departure charge to stay above 20% arrival:

  • Glenwood Springs → Denver area: the biggest climb of the return (+3,336 ft to 9,097 ft) — charge to 100% before leaving Glenwood Springs, not the usual 90%.
  • Amarillo → Weatherford: a long, hot 185-mi leg — charge to 100% before leaving Amarillo.

⚠️ Trinidad → Raton's net elevation change (+534 ft) understates real consumption — Raton Pass itself peaks at 7,834 ft between them, same situation as the outbound Flagstaff leg.
